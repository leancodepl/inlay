# leancode_add2app

An opinionated Flutter add-to-app framework for apps that embed Flutter inside a native iOS or Android host.

## Features

- **Type-safe navigation** between native and Flutter screens in both directions, with code-generated route classes for Dart, Swift, and Kotlin
- **Cross-platform state sharing** via a key-value storage layer synchronized across all Flutter engines and native code
- **Automatic engine management** based on `FlutterEngineGroup` — you never manage engines directly
- **Dialog and bottom sheet support** — Flutter-rendered overlays presented over native screens
- **Multiple routing integrations** — works with go_router, auto_route, or plain pattern matching
